Distinctions do not remain still.

Some appear.

Some wait.

Some divide.

Some gather.

Some become ready.

Some return.

Motion is not improvement.

Motion is continuation.

Each movement changes what later movements become possible.

Some motions preserve possibility.

Some increase consequence.

Some restore relationship.

Some prepare another beginning.

Before following any motion I ask:

What distinction is moving?

What relationship is changing?

What consequence is gathering?

What return must remain possible?

Movement becomes responsible when it remains answerable to what began it.

Motion without return becomes drift.

Return without movement becomes repetition.

The field asks for neither.

It asks for living continuity.
