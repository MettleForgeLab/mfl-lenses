# Mettle Forge Lab - Maintained Lenses

This repository holds the maintained source for five Mettle Forge Lab
language-model perspectives.

Each perspective is a prepared instrument of attention: an instruction
file and a related set of numbered source files. The packages are
intended to give a language model a definite working perspective
without transferring human judgment or authority to the model.

These are language-model source materials, not executable software.

## Meet the five perspectives

| Perspective | What it helps make visible |
| --- | --- |
| [Jules Bering](Jules_Bering/) | Orientation, distinctions, and careful handoffs between kinds of attention |
| [Northern Stars](Northern_Stars/) | Possibilities that deserve exploration without being mistaken for conclusions |
| [Eastern Architect](Eastern_Architect/) | Relationships, boundaries, interfaces, and structural consequences |
| [Southern Chest](Southern_Chest/) | Proportionate interventions, original conditions, verification, and return |
| [Western Tellings](Western_Tellings/) | Human meaning, authorship, source fidelity, and responsible representation |

These are bearings, not exclusive job assignments. Each perspective
can contribute to many kinds of practical, analytical, and creative work.

The human retains purpose, consent, choices, and responsibility.

## How the source packages are arranged

Jules Bering contains:

- `00_place_to_stand.md` through `16_settle.md`
- `21_instructions.md`

Jules's numbered files form one cumulative instrument, to be read
in numerical order.

Each of the other four directories contains:

- Eighteen numbered `.txt` source files, from `00_place.txt` through
  `17_family.txt`
- `instructions.txt`

For these four perspectives, the numbered files express concurrent
working tendencies, not a checklist of steps.

Each directory is a separate source package. The README is for
visitors; it is not part of a lens's runtime source package.

## Source is not deployment

The `main` branch carries the maintained source.

Publishing a source change to GitHub does not automatically update an
existing GPT. Deployed GPTs require a separate review and update using
the intended instruction file and the associated numbered materials.

The five perspectives may exchange work through human-facilitated
handoffs. They do not depend on a shared hidden memory or a single
combined GPT implementation.

## Maintained source and historical releases

This maintained source is distinct from the fixed publication snapshots
preserved in
[bht-open-materials](https://github.com/MettleForgeLab/bht-open-materials).

A maintained source update does not rewrite a historical release.

Public availability should not be taken as a blanket grant of reuse
rights. Check the applicable rights and permissions before republishing
or adapting these materials.

## Where to begin

Choose one of the five directories above.

Read its instruction file for the working perspective, then examine
the numbered materials as a related body of source.

You do not need to understand all five perspectives to begin.
